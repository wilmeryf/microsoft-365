# Principais atalhos do Excel

> **Data:** 19 e 20 de agosto de 2026

Os atalhos mais usados.

---

## Dica

Antes de iniciar com os atalhos, saiba disto:

### Ponto de inserção

- Ponto de inserção → indica o local onde o conteúdo será inserido ou editado.
- Ao selecionar uma célula e começar a digitar, o conteúdo será inserido nela.

Para que os atalhos funcionem, deve-se sair dele, clicando em ENTER ou em qualquer célula.

---

## Principais atalhos

### Desfazer e refazer

`Ctrl + Z` → desfaz uma ação ou várias ações.  
`Ctrl + Y` → refaz ações que foram desfeitas.

### Data e hora

`Ctrl + ;` → insere a data atual.  
`Ctrl + Shift + ;` → insere a hora atual.

### Movimentação pela planilha

`Scroll do mouse` → movimenta-se verticalmente pela planilha.  
`Page Up` → movimenta a visualização uma tela para cima.  
`Page Down` → movimenta a visualização uma tela para baixo.  
`Ctrl + Shift + Scroll` → movimenta-se horizontalmente pela planilha.  
`Alt + Page Up` → movimenta a visualização horizontalmente para a esquerda.  
`Alt + Page Down` → movimenta a visualização horizontalmente para a direita.  
`F5` → abre o recurso **"Ir para"**, permitindo acessar diretamente uma célula, como A500.

### Zoom

`Ctrl + Scroll do mouse` → aumenta ou diminui o zoom.

A porcentagem do zoom aparece no canto inferior direito da janela.

### Seleção

`Ctrl + T` → seleciona tudo, de acordo com o contexto da planilha.  
`Shift + Setas` → seleciona células utilizando as teclas direcionais, sem precisar do mouse.

Para interromper a seleção, solte o Shift e utilize uma tecla de direção.

### Arquivo e planilhas

`Ctrl + B` → salva as modificações na pasta de trabalho.  
`Shift + F11` → cria uma nova planilha.  
`Ctrl + clique + arrastar a aba da planilha` → cria uma cópia da planilha.  
`Ctrl + Page Up` → alterna para a planilha anterior.  
`Ctrl + Page Down` → alterna para a próxima planilha.

### Copiar, recortar e colar

`Ctrl + C` → copia o conteúdo selecionado.  
`Ctrl + V` → cola o conteúdo copiado.  
`Ctrl + X` → recorta o conteúdo selecionado.  
`Ctrl + X + Ctrl + V` → move o conteúdo selecionado para outro local.

### `Alt` - Acessar os menus pelo teclado

Ao pressionar `Alt`, o Excel mostra letras e combinações de teclas sobre os elementos da faixa de opções. Essas letras permitem acessar os comandos utilizando **apenas o teclado**.
